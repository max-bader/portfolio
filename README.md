# maxbader.dev — Personal Portfolio

My portfolio site: experience, research, and projects. Built with React + Vite.

## Develop

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
```

## Structure

- `src/data/` — projects and social links (edit these to update content)
- `src/components/` — one component per section (Hero, Experience, Projects, Contact)
- `public/` — resume, research paper PDF, images
